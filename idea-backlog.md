# Idea Backlog

- Improve loading messages: show meaningful progress or status updates instead of leaving users staring at a static error message.
- Reduce generation wait times: parallelize independent pre-generation checks, avoid duplicate credit-balance requests, batch sprite-history signed URLs, and consider a faster mode with less strict retry/QA behavior.
- Reference images: let users choose whether to use an image as visual inspiration or edit it directly.
- Asset management: allow selecting and deleting multiple saved assets at once.
- Asset metadata: add a name/title field for each generated asset.
